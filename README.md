# R_EnsRandMLP

Working script for ensemble multilayer perceptrons with random number of layers and neurons applied in R.

From master thesis "Mapping functional group distribution of soil organic matter with laboratory hyperspectral imaging and machine learning", Siwei Luo, 2019, TUM.
And for publication "Spatial molecular heterogeneity of POM during decomposition at different soil depths resolved by VNIR hyperspectral imaging", DOI: 10.1111/ejss.13207
